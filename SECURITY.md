# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Report them privately through GitHub Security Advisories:
<https://github.com/veniplex/wishy/security/advisories/new> (tab *Security › Report a vulnerability*).

Helpful: affected version, steps to reproduce, expected impact. We aim to acknowledge your report within a few days and
will get back to you with next steps. Please give us time to ship a fix before you publish details.

## Supported versions

Security fixes are provided for the latest stable version (`ghcr.io/veniplex/wishy:latest`).

## Operational notes

See the "Security notes" section in the [README](README.md) (including `secret.key` and Docker access for image updates).
